# Meal Orders

A private family PWA for kids to order meals from menus a parent builds.

- **Parents** build an item library (photo + category), create menus (pick items per meal, set how many of each a kid can choose, set an order-closing time), watch orders come in live, and mark meals closed/ready.
- **Kids** log in with a name + PIN on their iPad, order from the open menu within the countdown, see when their meal is ready, then upload a photo and pick a tip % once served.
- Everything served rolls into a public **Meal History** page (month list + wall-calendar view).

See [SETUP.md](./SETUP.md) for the one-time Firebase/Cloudinary setup this app needs before it runs.

Built with Vite + React + Firebase (Firestore + Auth) + Cloudinary, deployed to GitHub Pages.
